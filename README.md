# 🌿 WildGuard – Wildlife & Nature Conservation

**WildGuard** is a front-end web development project designed to raise awareness about wildlife conservation, endangered species, and environmental protection. It provides information about conservation initiatives and encourages visitors to take a pledge to protect nature.

## 📌 Project Overview

The website features a nature-inspired design with a green color scheme, wildlife imagery, informational cards, conservation project highlights, and a pledge form. It is built using HTML, CSS, and JavaScript.
live link = https://wildlife-and-nature-conservation.vercel.app/
## ✨ Features

- **Home Section:** Introduces the mission of protecting wildlife and preserving nature.
- **About Section:** Highlights habitat protection, anti-poaching, and reforestation.
- **Endangered Species:** Displays information about the Bengal tiger, African elephant, Scarlet macaw, and Hawksbill sea turtle.
- **Conservation Projects:** Showcases the Amazon Canopy Initiative and Safe Passage Corridors.
- **Wildlife Protection Pledge:** Collects a visitor's name and email through a form.
- **Interactive Form:** Uses JavaScript to display the submitted pledge details without reloading the page.
- **Responsive Styling:** Uses CSS Grid, Flexbox, and media queries to adapt the layout for different screen sizes.
- **Social Media Icons:** Includes Facebook, Twitter, Instagram, and YouTube icons.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Creates the structure and content of the website |
| CSS3 | Handles styling, layout, colors, hover effects, and responsiveness |
| JavaScript | Handles pledge form submission and displays the entered details |
| Font Awesome | Provides icons for navigation, conservation, and social media |

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd WildGuard
   ```

3. Make sure `index.html` and `style.css` are in the same directory.

4. Open `index.html` in your web browser.

   Alternatively, open the folder in Visual Studio Code and run the website using the **Live Server** extension.

## 💻 Website Sections

### 1. Home
A hero section with a wildlife background, a heading, and navigation buttons.

### 2. About Conservation
Explains the importance of protecting habitats, preventing poaching, and restoring forests.

### 3. Endangered Species
Presents wildlife cards with images, descriptions, and conservation-status labels.

### 4. Conservation Projects

## 🎯 Project Objectives

- Develop practical skills in HTML, CSS, and JavaScript.
- Understand semantic HTML elements and website sectioning.
- Apply CSS Grid and Flexbox for responsive layouts.
- Learn how JavaScript handles form events and DOM manipulation.
- Promote awareness of wildlife conservation and biodiversity.

- The category filter buttons and mobile menu require additional JavaScript to work.
- Some images and icons depend on external internet resources.
- The project is a front-end demonstration and does not include a backend.
